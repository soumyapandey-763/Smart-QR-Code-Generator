# Smart QR Code Generator

## 📌 Project Overview

Smart QR Code Generator is a web-based application that allows users to create different types of QR codes quickly and easily.

Users can generate QR codes for text, URLs, email, Wi-Fi networks, and contact information. The application also provides options to customize QR color and size, download or copy QR codes, and manage QR code history.

## 🚀 Features

- Generate QR code from text
- Generate QR code from URLs
- Generate Email QR code
- Generate Wi-Fi QR code
- Generate Contact / vCard QR code
- Change QR code color
- Change QR code size
- Download QR code as PNG
- Copy QR code to clipboard
- Clear generated QR code
- Save QR codes in browser history
- Generate QR again from history
- Delete individual history items
- Clear complete QR history
- Store history using Local Storage
- Responsive design for mobile devices
- Simple and user-friendly interface

## ⚙️ How to Run

1. Open the project folder in VS Code.
2. Open the project using Live Server.
3. Select the required QR type.
4. Enter the required information.
5. Select QR color and size.
6. Click on **Generate QR Code**.
7. Download or copy the generated QR code.

## 📚 QR Code Library

This project uses the **QRCode.js** JavaScript library to generate QR codes.

## 💾 Data Storage

QR history is stored locally in the browser using **Local Storage**.

The application stores the latest 10 generated QR codes.
